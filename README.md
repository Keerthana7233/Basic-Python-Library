# Basic Python Library Management System

A simple object-oriented Python program that manages a library book collection.

## Features

- Add books
- Search books by title
- Checkout books
- Return books
- Prevent duplicate ISBNs
- Save library data to JSON
- Load library data from JSON

## Files

- `library.py` - Main Python program
- `library.json` - Persistent library catalog

## How to Run

```bash
python library.py
